# 🎬 Movie Shorts Pipeline

Автоматическая нарезка Shorts/Reels/TikTok из локально скачанных фильмов **и стримов** (включая клипы и VOD Twitch) с автоматической публикацией постов в Telegram-канал.

## 🚀 Возможности

- **Два режима нарезки: фильмы и стримы** — переключаются в GUI и через `--source` в CLI
- **Нарезка стримов**: AI ищет яркие моменты по субтитрам записи, либо моменты задаются вручную (`ЧЧ:ММ:СС-ЧЧ:ММ:СС, ...`)
- **Контент Twitch**: клипы скачиваются по ссылкам и конвертируются в вертикальный формат; VOD тоже поддерживается
- **Выбор количества клипов** — счётчик в GUI и `--clips` в CLI
- **Автоматическое извлечение субтитров** из видеофайлов (встроенные дорожки или транскрибация через Whisper)
- **AI-анализ через Google Gemini**: для фильмов — сцены с конфликтом и твистами, для стримов — смешные и эпичные моменты
- **Вертикальный формат 9:16** с размытым фоном и двухстрочным оверлеем: «Название в шапке профиля» и крупный код
- **Отдельная папка для каждого источника** — все клипы, постер и описание лежат рядом
- **Готовое описание публикации** в текстовом файле с промо-хэштегами — просто копируй и вставляй в поле описания любой площадки
- **Публикация в Telegram** с форматированным постом (у стримов своё оформление)
- **SQLite база данных** для хранения информации и опубликованных постов

## 📋 Требования

- **Python 3.10+**
- **FFmpeg** (для обработки видео)
- **CUDA GPU** (опционально, для ускорения Whisper)

## 🔧 Установка

### 1. Установка FFmpeg

**Windows:**
```bash
winget install ffmpeg
```
или скачайте с https://ffmpeg.org/download.html и добавьте в PATH

**macOS:**
```bash
brew install ffmpeg
```

**Linux:**
```bash
sudo apt install ffmpeg
```

### 2. Установка зависимостей Python

```bash
cd movie_shorts_pipeline
pip install -r requirements.txt
```

### 3. Настройка окружения

Скопируйте `.env.example` в `.env` и заполните значения:

```bash
cp .env.example .env
```

#### Получение API ключей:

**Google Gemini API Key:**
1. Перейдите на https://aistudio.google.com/app/apikey
2. Создайте новый API ключ
3. Вставьте в `.env`: `GEMINI_API_KEY=ваш_ключ`

**Telegram Bot Token:**
1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям, получите токен
4. Вставьте в `.env`: `TELEGRAM_BOT_TOKEN=1234567890:ABCdef...`

**Telegram Channel ID:**
1. Создайте канал (если нет)
2. Добавьте бота как администратора канала с правами на публикацию
3. Узнайте ID канала:
   - Для публичного канала: `@channel_name`
   - Для приватного: отправьте сообщение в канал, затем перейдите на `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   - ID будет вида `-1001234567890`
4. Вставьте в `.env`: `TELEGRAM_CHANNEL_ID=-1001234567890`

## 📖 Использование

### Базовый запуск

```bash
python cli.py --input "путь/к/фильму.mkv" --title "Название фильма" --year 2024
```

### С публикацией в Telegram

```bash
python cli.py --input "путь/к/фильму.mkv" --title "Название фильма" --year 2024 --publish
```

### С указанием количества клипов

```bash
python cli.py -i movie.mkv -t "Фильм" -y 2024 -c 5 --publish
```

### Нарезка стрима (AI ищет моменты сам)

```bash
python cli.py -s stream -i stream.mp4 -t "Название стрима" -c 5
```

### Нарезка стрима с моментами вручную

```bash
python cli.py -s stream -i stream.mp4 -t "Название стрима" --moments "1:23:45-1:25:00, 2:00:10-2:01:00"
```

### Клипы Twitch пачкой → вертикальные шортсы

```bash
python cli.py --twitch https://clips.twitch.tv/Abc123 --twitch https://clips.twitch.tv/Def456
```

Пачка клипов Twitch отличается от фильмов: **код не рисуется на клипе и не пишется в описании** (используется только как внутренний идентификатор папки), а в хэштегах автоматически подставляются **стример и игра** из метаданных Twitch: `#стример #игра #twitch #shorts #reels`.

### VOD Twitch: скачать запись и нарезать

```bash
python cli.py --twitch https://www.twitch.tv/videos/123456789 -t "Стрим" -c 5
```

### Аргументы командной строки

| Аргумент | Краткий | Обязательный | Описание |
|----------|---------|--------------|----------|
| `--input` | `-i` | Да* | Путь к видеофайлу (mkv/mp4); *не нужен при `--twitch` |
| `--title` | `-t` | Да* | Название; *для клипов Twitch определяется из заголовка |
| `--year` | `-y` | Нет | Год выпуска (у стримов по умолчанию текущий) |
| `--clips` | `-c` | Нет | Количество клипов/моментов (по умолчанию 3) |
| `--source` | `-s` | Нет | Тип источника: `movie` (по умолчанию) или `stream` |
| `--moments` | | Нет | Моменты стрима вручную: `"ЧЧ:ММ:СС-ЧЧ:ММ:СС, ..."` |
| `--twitch` | | Нет | Ссылка на клип или VOD Twitch (можно несколько раз) |
| `--publish` | `-p` | Нет | Опубликовать в Telegram |
| `--env` | | Нет | Путь к .env файлу |

### Использование GUI

В окне приложения:
- **Клипов** — счётчик от 1 до 10 (работает во всех режимах);
- **Режим** — «Фильм» или «Стрим»; в режиме «Стрим» становится активным поле «Моменты» для ручных таймкодов (пусто = моменты ищет AI);
- **Twitch** — вставьте ссылки на клипы (через запятую), и пачка сконвертируется в вертикальные шортсы; ссылка на VOD обрабатывается как стрим.

## 🔍 Как это работает

### 1. Извлечение субтитров
- Проверяет наличие встроенных субтитров через `ffprobe`
- Если найдена русская дорожка — извлекает её
- Иначе транскрибирует аудио через `faster-whisper`

### 2. AI анализ
- Отправляет субтитры в Google Gemini (модель берётся из `GEMINI_MODEL`)
- Получает JSON с таймкодами вирусных сцен (40-75 секунд)
- Генерирует текст поста: жанр, синопсис, цепляющий факт

### 3. Рендер клипов
- Вырезает сцены по таймкодам
- Создает вертикальный формат 1080x1920:
  - Фоновый слой: размытое видео
  - Передний слой: оригинальное 16:9 по центру
  - Текстовый оверлей в две строки: «Название в шапке профиля» и код фильма
- Извлекает постер из середины сцены
- Все результаты складывает в отдельную папку `output/<код>_<Название>_<год>/`

### 4. Описание публикации
- В ту же папку пишется `description_<код>.txt` — plain-текст без HTML-разметки
- Состав: название и год, жанр, синопсис без спойлеров, интересный факт, строка про шапку профиля с кодом и число клипов
- Внизу — блок промо-хэштегов: `#кодXXXX`, жанровые теги, год и универсальные (`#кино #фильмы #shorts #reels #tiktok #чтопосмотреть`)

### 5. Публикация в Telegram
- Отправляет постер с текстом в канал
- Текст оптимизирован для поиска: `#кодXXXX` и `<code>XXXX</code>`
- Сохраняет `message_id` в базу данных

## 📺 Нарезка стримов и Twitch

### Три источника в режиме «Стрим»

1. **Локальная запись стрима + AI** — субтитры достаются из записи (обычно через Whisper), Gemini по стримовому промпту ищет яркие моменты (рофлы, фейлы, эпик-вин, реакции) длительностью 20–60 секунд:
   ```bash
   python cli.py -s stream -i stream.mp4 -t "Название стрима" -c 5
   ```
2. **Локальная запись + моменты вручную** — без AI, только рендер указанных кусков:
   ```bash
   python cli.py -s stream -i stream.mp4 -t "Название" --moments "1:23:45-1:25:00, 2:00:10-2:01:00"
   ```
   Время можно писать как `ЧЧ:ММ:СС`, так и `ММ:СС`, и просто секундами (`90-130`).
3. **Twitch** — ссылки на клипы пачкой конвертируются в вертикальные шортсы (каждый клип целиком, AI не нужен); ссылка на VOD скачивается через yt-dlp и нарезается как стрим:
   ```bash
   python cli.py --twitch https://clips.twitch.tv/Abc --twitch https://clips.twitch.tv/Def
   python cli.py --twitch https://www.twitch.tv/videos/123456789 -t "Стрим" -c 5
   ```

### Отличия стрим-режима от фильмов

- AI-промпт ищет **моменты** стрима, а не сцены фильма; в описании вместо жанра и синопсиса — тема и контекст моментов
- Длительность клипов 20–60 секунд — как раз формат Shorts и Reels; у фильмов — 40–75 секунд
- Хэштеги стримовые: `#стримы #стрим #twitch #shorts #reels #tiktok` + теги от AI
- В Telegram пост оформляется с пометкой «🎮 Стрим: ...»
- Год для папки и записи в базе по умолчанию — текущий

⚠️ Для скачивания с Twitch нужен **yt-dlp**: `pip install yt-dlp` (уже добавлен в requirements.txt). VOD многочасового стрима может весить десятки гигабайт — качайте его только если нужно, либо используйте локальный файл с моментами.

## 📺 Автоматическая загрузка в YouTube Shorts

Клипы можно выкладывать в YouTube прямо из GUI — кнопкой «Выложить в YouTube» или по вопросу после обработки. Разовая настройка:

1. Откройте https://console.cloud.google.com и создайте проект
2. **APIs & Services → Library** → включите **YouTube Data API v3**
3. **OAuth consent screen** → тип External → добавьте свой Google-аккаунт в **Test users** (приложение в режиме testing — это нормально, токен личный)
4. **Credentials → Create Credentials → OAuth client ID** → тип **Desktop app**
5. Скачайте JSON и сохраните как `client_secrets.json` в папку проекта

При первой загрузке откроется браузер для входа в Google; токен сохранится в `youtube_token.json` и будет переиспользоваться.

Настройки в `.env`:
```env
YOUTUBE_PRIVACY=public          # public, unlisted или private
YOUTUBE_CLIENT_SECRETS=         # путь к client_secrets.json (по умолчанию в папке проекта)
YOUTUBE_TOKEN=                  # путь к youtube_token.json
YOUTUBE_CATEGORY_ID=24          # 24 = Entertainment
```

⚠️ **Квота:** загрузка одного видео — 1600 юнитов из 10 000 в день (по умолчанию ~6 клипов в день). Клипы ≤3 минут в вертикальном формате YouTube сам помечает как Shorts.

## 🐛 Решение проблем

### "FFmpeg не найден"
Установите FFmpeg и убедитесь что он добавлен в PATH:
```bash
ffmpeg -version
```

### "faster-whisper не установлен"
```bash
pip install faster-whisper
```

### "Telegram API error: chat not found"
- Проверьте `TELEGRAM_CHANNEL_ID` в `.env`
- Убедитесь что бот добавлен в канал как администратор
- Для приватных каналов ID должен начинаться с `-100`

### "Gemini API error"
- Проверьте `GEMINI_API_KEY` в `.env`
- Убедитесь что ключ активен на https://aistudio.google.com

## 📊 База данных

Таблица `movies_posts`:
- `code` — уникальный 4-значный код фильма
- `title` — название
- `year` — год выпуска
- `genre` — жанр
- `tg_msg_id` — ID сообщения в Telegram
- `clip_paths` — JSON с путями к клипам
- `poster_path` — путь к постеру
- `created_at` — дата создания
